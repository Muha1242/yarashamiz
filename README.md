# Yarashamiz boti
1. `yarashamiz.html` ni GitHub Pages ga joylang (Settings > Pages). Manzil https bo'ladi.
2. @BotFather dan token oling.
3. Serverda: `pip install -r requirements.txt`, so'ng
   `BOT_TOKEN=... WEBAPP_URL=https://<login>.github.io/<repo>/yarashamiz.html python bot.py`
Bot doimo ishlab turishi kerak (arzon VPS, Railway yoki Render). GitHub Pages faqat HTML uchun.
